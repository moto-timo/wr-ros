# wr-ros

## Overview

wr-ros provides recipes for integrated the meta-ros layer with Wind River Linux.

The contents of this git repository was based on Wind River Linux 10.21. That
release is no longer supported. The latest releases of Wind River Linux may
use the [meta-ros](https://github.com/ros/meta-ros) layer directly.
